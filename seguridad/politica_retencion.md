
# Política de retención de datos

## 1. Objetivo

Establecer medidas para conservar y eliminar de forma segura los datos utilizados en el proyecto de aeropuerto y aerolínea regional.

## 2. Datos utilizados

El proyecto trabaja con información de vuelos, rutas, aeronaves, tripulación, reservas, pasajeros y condiciones meteorológicas.

Los datos de pasajeros requieren especial protección porque incluyen nombres y números de pasaporte.

## 3. Conservación de datos

- Los datos operativos se conservarán durante el desarrollo y las pruebas del proyecto.
- Los datos personales sintéticos se utilizarán únicamente con fines académicos.
- Los datos de la zona raw se conservarán mientras sean necesarios para verificar el procesamiento.
- Los datos de las zonas curated y rejected se conservarán para comprobar las reglas de calidad.
- Los respaldos se conservarán durante el período de pruebas y validación.

## 4. Eliminación de datos

Cuando los datos dejen de ser necesarios:

- Se eliminarán los archivos temporales.
- Se eliminarán los respaldos que ya no sean necesarios.
- Se evitará conservar copias innecesarias de información personal.
- Se comprobará que los archivos eliminados no sean requeridos para restaurar el proyecto.

## 5. Protección de datos personales

El acceso a nombres y pasaportes estará restringido según los permisos asignados.

Los reportes del dashboard utilizarán información agrupada para evitar mostrar datos personales.

## 6. Revisión de la política

La política se revisará cuando cambien las fuentes de datos, los procesos de almacenamiento o los requisitos de seguridad.
